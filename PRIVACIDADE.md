# Política de privacidade do Office

O Office é um programa de computador que roda na máquina de quem o instala. Esta política vale para o acesso que ele pede
à conta Google (Google Drive).

## O que o Office acessa

- Os arquivos e as pastas do Google Drive da conta que fez o login, pela API do Google Drive.
- O endereço de e-mail dessa conta, só para mostrar qual conta está conectada.

## Para que usa

- Pôr no Meu Drive um atalho de uma pasta compartilhada com a conta.
- Copiar arquivos e pastas de um lugar do Drive para outro, dentro da mesma conta.

O Office só cria atalhos, pastas e cópias. Ele não apaga, não move e não compartilha arquivos.

## Onde os dados ficam

- A autorização (token) fica guardada só no computador onde o Office está instalado, na pasta de dados do programa.
- O Office não envia arquivos, conteúdo nem dados da conta para servidores próprios ou de terceiros. As chamadas vão
  direto do computador para a API do Google.
- Nenhum dado é vendido, cedido ou usado para publicidade.

O uso e a transferência de informações recebidas das APIs do Google seguem a
[Política de dados do usuário dos serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy),
incluindo os requisitos de uso limitado.

## Como revogar

Na página Equipe do Office, clique em **Desconectar**. Também dá para remover o acesso em
[myaccount.google.com/permissions](https://myaccount.google.com/permissions).
